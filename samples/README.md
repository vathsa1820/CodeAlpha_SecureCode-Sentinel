# Source Code Samples

This directory holds Python source code samples used for testing and validating the SecureCode Sentinel SAST scanner engine.

## Structure
- `vulnerable/`: Sample Python code snippets containing intentional security flaws (e.g. SQL injection, hardcoded secrets, unsafe deserialization, command injection) for testing scanner detection capabilities.
- `secure/`: Remediated and secure versions of the Python samples demonstrating proper secure coding practices.
